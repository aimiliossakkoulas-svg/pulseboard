# Snowboard Growth Workspace

A simple personal workspace for tracking snowboard skills, technique issues, and improvement reminders.

## What it includes
- A place to list the snowboard skills or techniques you want to improve.
- A notes area for recording what felt flawed and what needs attention.
- Gentle reminders for returning to the basics and practicing with patience.

## Open it
Open [index.html](index.html) in your browser to start using the workspace.
